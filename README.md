# Tokemon

윈도우 데스크톱에서 피카츄를 키우고 라이츄로 진화시키는 Electron 앱입니다.

## 실행

### Windows 실행 파일

v0.3.0 빌드 결과는 `dist/Tokemon-0.3.0-win-x64.exe`입니다. Windows x64용이며 Node.js 설치가 필요 없습니다. 두 몬스터의 이미지와 울음소리, 레벨업·진화 효과음을 포함합니다. 위치와 성장 기록은 `%APPDATA%/Tokemon`에 저장합니다.

v0.3.0은 빌드 PC에서 포터블 exe를 네트워크 없이 실행하는 검사(`node scripts/packaged-smoke.cjs`)를 통과했으며 [최신 릴리스](https://github.com/insu0929/tokemon/releases/latest)에서 받을 수 있습니다. v0.2.0은 당시 빌드 PC의 Windows Application Control 정책으로 exe 실행이 차단되어 배포 검증을 하지 못했고, 정식 릴리스하지 않았습니다.

이 실행 파일은 코드 서명되지 않았습니다. Windows에서 게시자 확인 경고가 표시될 수 있습니다.

개발 환경에서 `npm.cmd install` 후 `npm.cmd run build:win`으로 다시 만들 수 있습니다. 빌드 결과는 `dist/`에 생성됩니다.

### 소스 코드 실행

Node.js 설치 후 이 폴더에서 실행합니다. PowerShell 실행 정책과 관계없이 `npm.cmd`를 사용할 수 있습니다.

```powershell
npm.cmd install
npm.cmd start
```

- 왼쪽 클릭: 현재 몬스터의 울음소리. 재생 중 연속 클릭은 무시합니다.
- 왼쪽 버튼으로 드래그: 화면에서 위치 이동. 드래그 종료 시 울지 않습니다.
- 오른쪽 클릭: 음소거, 위치 초기화, 종료.
- 마지막 위치는 다음 실행에 복원됩니다. Alt+F4로도 종료할 수 있습니다.
- 말풍선과 하단 HP 바는 몬스터 표시 폭에 맞춰집니다. 아래의 **잔여량 체험** 슬라이더로 상태를 확인할 수 있습니다. 실제 토큰 잔여량은 아직 연동하지 않았으며 실행 시 100%로 시작합니다.
- 70~100%: 활발(빠른 움직임·점프), 50~70% 미만: 정상, 10~50% 미만: 약해짐(느린 움직임), 0~10% 미만: 기절(정지하며 쓰러짐). 잔여량을 올리면 다시 회복합니다.
- 상태 변경과 클릭 시 기본 울음소리의 속도·음높이·볼륨을 바꿔 재생합니다. 기절 중 클릭은 무음이고 기절 상태 진입 때만 울어요. 원작의 상태별 전용 음원·이미지가 아닌 앱의 연출입니다.
- OS의 동작 줄이기 설정에서는 반복 애니메이션을 멈춥니다.
- 이미지·음원은 `assets/`에 포함되어 있습니다. 누락된 경우에만 인터넷으로 다운로드합니다.
- 투명한 작은 창을 일반 앱 위에 표시합니다. 독점 전체화면 게임이나 Windows 보안 화면 위의 표시는 보장하지 않습니다.
- 이 MVP는 작은 사각형 창 영역에서 마우스 입력을 받습니다. 투명한 픽셀 단위 클릭 통과는 아직 구현하지 않았습니다.

## 범위

피카츄 → 라이츄 진화, EXP 및 레벨, 드래그 이동, 울음소리, HP 바와 잔여량 체험 슬라이더, 네 가지 상태에 따른 애니메이션·음원 변형, Windows x64 포터블 실행 파일을 제공합니다. 실제 토큰 연동, 다른 몬스터, 도감, 설치 마법사, 배틀, 자동 업데이트는 포함하지 않습니다. 다른 OS는 검증하지 않았습니다.

## EXP와 진화 체험

- HP 바로 아래 파란 EXP 바와 레벨이 표시됩니다. Lv.1, 0 EXP로 시작합니다.
- **사용 토큰 체험**에 토큰 수를 입력하고 **추가**를 누르면 누적됩니다. 실제 서비스의 사용량은 아직 읽지 않습니다.
- 100토큰 = 1 EXP, 레벨당 100 EXP입니다. 100토큰 미만의 나머지도 보존합니다.
- 누적 40,000토큰(400 EXP), Lv.5에 도달하면 빛나는 연출 후 라이츄로 진화하며 이미지와 울음소리가 바뀝니다. 한 번에 `40000`을 추가하면 바로 체험할 수 있습니다.
- 초과 경험치는 다음 레벨에 반영되며 라이츄로 진화한 뒤에도 레벨이 오릅니다. HP 잔여량 체험은 EXP에 영향을 주지 않습니다.
- 성장 기록은 `progress.json`에 자동 저장되어 앱 재실행 시 복원됩니다. 개발 실행은 `.local/`, exe 실행은 `%APPDATA%/Tokemon`을 사용합니다.
- 진화를 다시 체험하려면 우클릭 → **성장 초기화 · Lv.1 피카츄로**를 선택하고 `40000`토큰을 추가하세요. 초기화 전 기록은 같은 폴더의 `progress-before-reset.json`에 백업됩니다. 경험치 추가·진화 진행 중에는 초기화하지 않습니다.
- 레벨 진화는 이 앱의 체험 규칙입니다. `src/progression.cjs`에서 변환 비율, 레벨당 EXP와 종별 진화 조건을 설정할 수 있습니다.
- 레벨·EXP는 저장 직후 바로 갱신됩니다. 기존 효과음 뒤에 팡파르가 이어지며, 팡파르 끝의 약 2.9초 무음을 제거했습니다. 한 번에 여러 레벨을 올려도 한 세트만 재생합니다.
- 진화는 레벨업 소리가 끝난 뒤 시작합니다. 피카츄 울음소리 → 원본 약 3~11초와 15~20.46초를 이어 붙인 진화 BGM(13.44초) → 라이츄로 바뀌며 울음소리 전체 재생 → 원본 약 21.41초부터의 성공 BGM 순서입니다. 녹화에 포함된 다른 포켓몬의 울음소리와 무음을 제거했고, 각 소리가 끝나면 다음 소리가 이어집니다. 전체 진화는 약 19초입니다.
- 파형의 낮은 진폭 지점에서 32ms 크로스페이드로 반복 구간을 연결하고, BGM 음량을 두 포켓몬 울음소리의 평균 체감 음량에 맞춰 보정했습니다. 동작 줄이기 설정은 시각 효과만 줄이며, 음소거 중에도 진화 애니메이션 구간은 유지합니다.
- 원본 약 16초의 효과음 구간(편집 BGM 시작 후 약 8.98초)에 라이츄의 검은 실루엣과 반짝이는 윤곽을 표시합니다. 색상과 이름은 아직 공개하지 않고, 라이츄 울음소리가 시작될 때 본 모습과 이름을 함께 공개합니다.
- 원본 7.5~8초 효과음이 끝나는 지점(편집 BGM 약 4.96초)부터 피카츄와 검은 라이츄 실루엣이 0.4초씩 번갈아 보입니다. 약 8.98초에 라이츄 실루엣으로 고정됩니다. OS 동작 줄이기 설정에서는 교차 점멸을 생략합니다.
- 두 스프라이트는 꼬리·귀를 포함한 이미지 중심 대신 몸통 축과 발 바닥선을 기준으로 정렬합니다. 진화 중 GIF 포즈는 고정하고, 교차할 때는 공통 바닥 기준점 주위로 크기가 60~100%를 오갑니다. 가장 작아진 순간 다음 모습으로 교체한 뒤 다시 커지므로 좌우로 이동하지 않습니다. 교차가 끝나면 실루엣이 원래 크기로 부드럽게 돌아오며, 본 모습 공개 뒤에도 같은 정렬을 유지합니다.
- 우클릭 음소거는 울음소리, 레벨업 효과음, 진화 BGM을 모두 즉시 멈춥니다. 음원 재생에 실패해도 경험치 저장과 진화는 계속 진행됩니다.

## 데이터 출처

- 이미지: https://github.com/PokeAPI/sprites
- 울음소리: https://github.com/PokeAPI/cries
- 레벨업 효과음: [PokéRogue assets](https://github.com/pagefaultgames/pokerogue-assets). 추가 팡파르·진화 BGM은 사용자가 지정한 YouTube 영상에서 가져왔습니다. 파일별 출처와 추출 구간은 [assets/audio/SOURCES.md](assets/audio/SOURCES.md)에 기록합니다. 음원은 로컬에 포함되어 오프라인으로 재생됩니다.

Pokémon 관련 캐릭터·이미지·음원의 권리는 각 권리자에게 있습니다. 이 프로젝트는 비공식 팬 프로젝트이며 해당 자료에 대한 권리를 주장하지 않습니다.

## 개발

`npm.cmd run check`로 JavaScript 구문을 검사합니다.

`npm.cmd test`는 경험치 경계, 여러 레벨 상승, 직렬 저장, 잘못된 입력 및 재시작 후 복원을 검사합니다. `npm.cmd run test:smoke`는 별도의 임시 프로필에서 EXP → 진화와 화면 재로드 후 복원까지 검증하므로 사용자의 성장 기록을 변경하지 않습니다.

빌드 후 `node scripts/packaged-smoke.cjs`로 실제 포터블 실행 파일의 오프라인 리소스 로딩(두 몬스터와 성장 효과음), 애니메이션, 기절 및 회복을 검사할 수 있습니다. Node.js 22 이상과 비어 있는 로컬 포트 19387이 필요합니다.

`npm.cmd run test:smoke`는 실제 Electron 창에서 GIF 프레임 디코딩, 오디오 재생 상태, 합성 포인터 이벤트에 따른 창 이동, 클릭/드래그 구분, 음소거, 상태 경계값, 기절 시 정지·무음 및 회복을 검사합니다. 실행 중인 앱을 종료한 후 실행하세요. 실제 마우스 조작과 스피커 출력은 별도로 확인해야 합니다.
