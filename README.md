# Tokemon

윈도우 데스크톱에 피카츄를 띄우는 최소 Electron 앱입니다.

## 실행

### Windows 실행 파일

[GitHub Releases](https://github.com/insu0929/tokemon/releases/latest)에서 `Tokemon-0.1.0-win-x64.exe`를 받아 더블 클릭하면 됩니다. 로컬 빌드 결과는 `dist/`에도 있습니다. Windows x64용이며 Node.js 설치가 필요 없습니다. 이미지와 울음소리를 포함하므로 인터넷 없이 실행할 수 있습니다. 위치와 캐시는 `%APPDATA%/Tokemon`에 저장합니다.

이 실행 파일은 코드 서명되지 않았습니다. Windows에서 게시자 확인 경고가 표시될 수 있습니다.

개발 환경에서 `npm.cmd install` 후 `npm.cmd run build:win`으로 다시 만들 수 있습니다. 빌드 결과는 `dist/`에 생성됩니다.

### 소스 코드 실행

Node.js 설치 후 이 폴더에서 실행합니다. PowerShell 실행 정책과 관계없이 `npm.cmd`를 사용할 수 있습니다.

```powershell
npm.cmd install
npm.cmd start
```

- 왼쪽 클릭: 피카츄 울음소리. 재생 중 연속 클릭은 무시합니다.
- 왼쪽 버튼으로 드래그: 화면에서 위치 이동. 드래그 종료 시 울지 않습니다.
- 오른쪽 클릭: 음소거, 위치 초기화, 종료.
- 마지막 위치는 다음 실행에 복원됩니다. Alt+F4로도 종료할 수 있습니다.
- 말풍선과 하단 HP 바는 몬스터 표시 폭에 맞춰집니다. 아래의 **잔여량 체험** 슬라이더로 상태를 확인할 수 있습니다. 실제 토큰 잔여량은 아직 연동하지 않았으며 실행 시 100%로 시작합니다.
- 70~100%: 활발(빠른 움직임·점프), 50~70% 미만: 정상, 10~50% 미만: 약해짐(느린 움직임), 0~10% 미만: 기절(정지하며 쓰러짐). 잔여량을 올리면 다시 회복합니다.
- 상태 변경과 클릭 시 기본 울음소리의 속도·음높이·볼륨을 바꿔 재생합니다. 기절 중 클릭은 무음이고 기절 상태 진입 때만 울어요. 원작의 상태별 전용 음원·이미지가 아닌 앱의 연출입니다.
- OS의 동작 줄이기 설정에서는 반복 애니메이션을 멈춥니다.
- 최초 이미지·음원 다운로드에는 인터넷이 필요합니다. 이후 `.local/assets` 캐시를 사용합니다.
- 투명한 작은 창을 일반 앱 위에 표시합니다. 독점 전체화면 게임이나 Windows 보안 화면 위의 표시는 보장하지 않습니다.
- 이 MVP는 작은 사각형 창 영역에서 마우스 입력을 받습니다. 투명한 픽셀 단위 클릭 통과는 아직 구현하지 않았습니다.

## 범위

피카츄 한 마리, 드래그 이동, 울음소리, HP 바와 잔여량 체험 슬라이더, 네 가지 상태에 따른 애니메이션·음원 변형, Windows x64 포터블 실행 파일을 제공합니다. 토큰 연동, 성장, 도감, 설치 마법사, 배틀, 자동 업데이트는 포함하지 않습니다. 다른 OS는 검증하지 않았습니다.

## 데이터 출처

- 이미지: https://github.com/PokeAPI/sprites
- 울음소리: https://github.com/PokeAPI/cries

Pokémon 관련 캐릭터·이미지·음원의 권리는 각 권리자에게 있습니다. 이 프로젝트는 비공식 팬 프로젝트이며 해당 자료에 대한 권리를 주장하지 않습니다.

## 개발

`npm.cmd run check`로 JavaScript 구문을 검사합니다.

빌드 후 `node scripts/packaged-smoke.cjs`로 실제 포터블 실행 파일의 오프라인 리소스 로딩, 애니메이션, 기절 및 회복을 검사할 수 있습니다. Node.js 22 이상과 비어 있는 로컬 포트 19387이 필요합니다.

`npm.cmd run test:smoke`는 실제 Electron 창에서 GIF 프레임 디코딩, 오디오 재생 상태, 합성 포인터 이벤트에 따른 창 이동, 클릭/드래그 구분, 음소거, 상태 경계값, 기절 시 정지·무음 및 회복을 검사합니다. 실행 중인 앱을 종료한 후 실행하세요. 실제 마우스 조작과 스피커 출력은 별도로 확인해야 합니다.
